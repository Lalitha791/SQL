# SQL


SQL (Structured Query Language) is a standard programming language used to create, manage, retrieve, and manipulate data stored in relational databases.

Example:

sql
SELECT * FROM Employees;
This query retrieves all records from the Employees table.

Uses of SQL:

Create and manage databases and tables.

Insert, update, and delete data.

Retrieve data from databases.

Filter, sort, and analyze data.
